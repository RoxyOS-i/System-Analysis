# 我的 Git 学习笔记

## 第一次 Git 实验总结

1. `git add` 的作用是：
   把工作区里改动的文件放进暂存区（index），挑出这次提交要包含哪些改动。它本身不保存历史，只是准备快照；`git diff --staged` 看到的就是这一步挑出来的内容。

2. `git commit` 的作用是：
   把暂存区里的内容打包成一条提交，写进本地仓库的历史，带上说明和作者信息。提交后 `git log` 能看到记录，但它还只在本地，远程仓库里没有。

3. 本次实验中 `git restore notes.md` 的作用是：
   把 `notes.md` 在工作区的修改撤销掉，恢复到最近一次提交（HEAD）的版本，也就是丢弃我追加的那句"准备放弃的练习文字"。同一个命令后来也用来恢复被 `rm` 删掉的 `plan.md`——既撤销修改，也恢复删除，前提是这些改动还没 commit。

4. `commit` 与 `push` 的区别是：
   `commit` 只把改动记进本地仓库的历史，`push` 才把本地提交上传到远程仓库（我这次推到 origin 的 `homework/zgypx228` 分支）。可以先在本地 commit 多次再一次性 push；push 之前别人在远程看不到，也不会产生 PR。
